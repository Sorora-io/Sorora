# Sorora frontend

This directory contains Sorora's React and TypeScript web application.

See the [project README](../README.md) for the product overview, matching algorithm, privacy model, Supabase setup, testing, and deployment instructions.

After completing that setup, run commands from this directory:

```bash
npm start                       # Local development
npm test -- --watchAll=false     # Frontend tests
npm run build                   # Production build
```
